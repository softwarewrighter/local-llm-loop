- Implemented CLI argument parsing for `--model`, `--iterations`, and `--verbose` in `src/main.rs`.
- Wrote a basic `run_loop` that spawns `opencode --model <model>` for each iteration.
- Generated documentation under `docs/` (architecture, prd, design, plan).
